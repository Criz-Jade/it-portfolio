# Crizalrie Jade Gadiano — IT Portfolio

## Files

- `index.html` — the structure/content of the website
- `style.css` — the visual design and responsive layout
- `script.js` — small JavaScript enhancement

## How to view it

1. Put all three files in the same folder.
2. Double-click `index.html`.
3. It should open in your web browser.

## Before publishing

Replace:
- `your-email@example.com` with your real professional email.
- The GitHub `#` link with your GitHub profile when you have one.
- Project placeholder/details with your actual lab information.
- Add your resume file when we create the resume button.
